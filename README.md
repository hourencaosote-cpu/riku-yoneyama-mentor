# RIXA

米山陸による、NCEA学習・海外大学進学・留学生活のオンライン個別サポート公式サイトです。

## Website

[https://riku-yoneyama-mentor.axcleez.chatgpt.site](https://riku-yoneyama-mentor.axcleez.chatgpt.site)

## Support

- NCEAの仕組みと科目別学習戦略
- 海外大学・専攻・奨学金の比較と進路設計
- 出願準備、書類、面接対策
- 週次計画と振り返り
- 留学生活を含む継続メンタリング

本人がYear 11のつまずきから学習方法を立て直し、5大学すべてから合格・奨学金オファーを受けた経験をもとにしています。本人の出願結果と、サポートを受ける方の成果は明確に区別して掲載しています。

## Development

```bash
npm install
npm run dev
```

検証:

```bash
npm run lint
npm test
```

## Stack

- React / TypeScript
- Next.js互換のVinext
- Cloudflare Workers互換ビルド

大学キャンパス写真の撮影者・ライセンスは、サイト内の実績ページに掲載しています。
